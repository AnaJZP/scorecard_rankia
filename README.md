# Scorecard regulatorio Premios Rankia 2026

Sitio HTML estático para comparar los brokers, casas de bolsa, fintechs y mercados de derivados galardonados en Rankia 2026 con enfoque regulatorio.

## Publicación en GitHub Pages

1. Subir `index.html` a la raíz del repositorio.
2. En GitHub: Settings > Pages > Build and deployment > Source: Deploy from a branch.
3. Seleccionar branch `main` y carpeta `/root`.
4. Guardar. La página quedará disponible en una URL similar a:
   `https://anajzp.github.io/scorecard_rankia/`

## Nota

El tablero es informativo. La regulación de brokers internacionales depende de la entidad legal que atienda al cliente, la jurisdicción y los términos contractuales.
